## System Management

| Command | Description |
|---|---|
| `history` | Display commands previously executed by the current user |
| `free` | Display system memory usage |
| `cat /proc/meminfo` | Display detailed memory information |
| `cat /proc/cpuinfo` | Display detailed CPU information |
| `uname -a` | Display kernel and system information |
| `du` | Display disk space used by files and directories |
| `whereis <command>` | Show possible locations of a command |
| `which <command>` | Show the command that will run by default |
