# Files and Directories

## Basic Linux Commands 

| Command | Description |
|---|---|
| `date` | Show the current date and time |
| `cal` | Show this month's calendar |
| `uptime` | Show how long the system has been running |
| `whoami` | Show which user you are logged in as |
| `finger` | Display information about a user |
| `users` | Show the users currently logged in |
| `id` | Show user and group information |
| `man <command>` | Show the manual page for a command |
| `username` | This is not a standard Linux command |
| `who` | Display who is logged in |
| `w` | Display who is logged in and what they are doing |



## View Files

| Command | Description |
|---|---|
| `ls` | List files and directories |
| `cat <filename>` | Display the full contents of a file |
| `less <filename>` | View a file page by page with navigation |
| `more <filename>` | View a file one page at a time |
| `head <filename>` | Display the first 10 lines of a file |
| `tail <filename>` | Display the last 10 lines of a file |
| `page <filename>` | Display a file page by page |

## Create and Delete Files and Directories

| Command | Description |
|---|---|
| `touch <filename>` | Create an empty file |
| `cat > <filename>` | Create a file and write content into it |
| `nano <filename>` | Open a file in Nano, or create it if it does not exist |
| `vi <filename>` | Open a file in Vi, or create it if it does not exist |
| `rm <filename>` | Remove a file |
| `mkdir <directory>` | Create a directory |
| `rmdir <directory>` | Remove an empty directory |
| `rm -rf <directory>` | Forcefully remove a directory and everything inside it |
