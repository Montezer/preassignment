# Manage files and directories 

## Commands to manage files and directories

| Command | Description |
|---|---|
| `cp <source> <destination>` | Copy a file or directory |
| `mv <source> <destination>` | Move or rename a file or directory |
| `find <location> -name <filename>` | Search for a file or directory |
| `grep <pattern> <filename>` | Search for a pattern inside a file |
| `cd <directory>` | Change to another directory |
| `diff <file1> <file2>` | Compare the differences between two files |
| `sed` | Search for and replace text patterns |
| `chmod` | Change file or directory permissions |
| `chown` | Change the owner of a file or directory |
| `file <filename>` | Display the type of a file |


### Grep Command
------
Grep = Global Regular Expression Print 
- It is used pick out the required expression from the file and print the output. 

### Sed Command 
------
SED = Stream Editor - Used to search word in the file and replace it with the word required to be in the output. 

- Note : It will only modify the output, but there will be no change in the original file.
