# Predictability Benefit of Cloud Computing 

Predictability = The ability to forecast and control the performance and behaviour of a system 
- Includes ability to predict future costs 


## Why is it needed? 
- It gives you the confidence that the system will continue to perform at the expected level in the future. 
- To help avoid crazy bills 

## How is this achieved? 
- Autoscaling 
- Load balancing 
- Different instance types, sizes, pricing tiers 
- Cost management tools 
- API for budgeting
