# Managability Bneefit of Cloud Computing 
- The ability to manage the applications IN the cloud and the ability to manage the cloud itself. 

## Management of the Cloud

##### All the ways to manage your own applications provided by your cloud provider such as Azure: 

- Templates 
- Automation 
- Scaling 
- Monitoring and alerts 
- Self healing 

## Management in the Cloud
- Web portal
- Command line interface and scripts 
- APIs - to access cloud 
- Powershell 

## Why is it need to manage the cloud? 
- Because it can impact costs, performance, security and other priorities 
- Different cloud vendors are going to be easier or harder to work with due to different interfaces

## How is it achieved in Azure? 
- Azure Portal, CLI, Powershell, Cloudshell, REST APIs and other programmatic methods 
- Consolidated monitoring and alerting system 
- Ability to use ARM templates, Bicep, Terraform etc
- Autoscaling most types of compute resources
