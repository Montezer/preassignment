# Elasticity Benefit of Cloud Computing 

Elasticity = The ability of a system to quickly and easily scale up or down the amount of resources that a system uses in response to changing demand. 
- Much like Hisoka and his bungee gum

## Quickly and Easily 
- Involves a type of automation 
- Called Autoscaling in cloud computing 
- The system monitors a metric, like CPU utilisation 
- Adds resources when it exceeds a limit for being busy 
- Remove resources when it falls below a limit for being not busy 

## Why is it needed? 
- More efficient 
- Cost effective of resources 
- Minise computing waste
