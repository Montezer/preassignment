# Scalabiliy Benefit of Cloud Computing

Scalability = The ability of a system to accomodate increasing demand by adding or removing resources as needed.  

## Why is it needed? 
- So that a system can adapt to changing usage patterns and handle increased traffic without requiring changes to the application code or system design. 

### Load Balancing
- The method of sharing computer work & internet traffic evenly across a group of different computers or servers. 

## Vertical Scaling 
- Adding more resources to a single server
- Increase the amount of memory, the number of CPUs
- Problem: there is an upper limit
- In Azure - 96 vCPUs, 384 GB memory 
- Does not improve availability 

## Horizontal Scaling 
- Also known as scaling out 
- Adding more servers to a system 
- No limits to scaling 
- Makes it more complex for load balancing 
- Has potential to improve system availability
